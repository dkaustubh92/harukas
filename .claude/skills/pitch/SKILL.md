# The pitch

**30% of the rubric** — the largest single bucket. HA owns this from 10:45, in parallel with the build.

## Narrative arc

Four beats, in this order. The order is load-bearing.

| Beat | Content | Trap |
|---|---|---|
| **Who hurts** | One real Haligonian, one concrete Tuesday | Statistics before a human |
| **Why now** | What changed — data available, cost fell, the problem got worse | "It's always been a problem" |
| **What we built** | One sentence. What it is, not how | Architecture. Nobody scores your stack here |
| **What changes** | Real number, from real data | Vague "empowering communities" |

## Rules

- **Problem before product.** Never open with the name. The room must feel the problem before you offer the cure
- **One person, not a population.** "Maria in Spryfield reported a broken streetlight in November. It's March." beats any aggregate
- **The number must be real.** Derived from an actual query (`halifax-data`). A judge asking "where's that from?" and seeing a live query is a scoring moment
- **Say it out loud.** Slides are read differently than they're spoken. Rehearse aloud from the first draft
- **Local specificity wins.** Name real neighbourhoods, real streets, real municipal processes. A Halifax room notices immediately

## Deck

Minimal. The demo is the star; slides are scaffolding. **Five slides maximum:**

1. **The problem** — one image, one sentence
2. **The person** — who hurts, concretely
3. **[DEMO]** — a placeholder slide so you don't forget to switch
4. **How it works** — one diagram, 15 seconds of talking
5. **Impact** — the number, and what's next

Use the `pptx` skill to build it. Match `creative-ui-ux-director`'s palette so the deck and the product look like one thing.

## Delivery

- **HA presents, KD drives the laptop** (`two-lane`)
- **Rehearse to 80 seconds** — live runs always go long
- **Do not read slides.** They're a backdrop
- **Hand the keyboard to a judge** during the demo. It's the strongest move available
- **Land the last line.** Write the closing sentence word-for-word and memorize it. It's the last thing scored
