# Three-minute demo script

**Current rehearsal script, 12 September 2026.** Follows the
[product requirements](product-requirements.md). This script does not replace
the acceptance checklist or prove that the flow has been built.

Prepare the citizen phone, separate officer laptop, a suitable tree photo, and one
seeded reported obstruction. Open the deployed URL on both devices.

| Time | Screen and action | Point to explain |
|---|---|---|
| 0:00–0:20 | Citizen phone opens map and a reviewed obstruction | Residents can see reported access problems and contribute a new report. The map is a labelled demo, not an official closure feed |
| 0:20–0:55 | Upload photo, choose location, confirm tree pin, and analyze | A photo and location become a structured draft. Explain the visible inputs while Luna runs |
| 0:55–1:15 | Correct one suggested field, review, and submit | The citizen controls the final report. Show its saved reference |
| 1:15–1:50 | Laptop receives the same report. Open photo and priority reasons | Staff see evidence and missing information together. The priority supports inspection decisions |
| 1:50–2:15 | Toggle **If unresolved**, then record an obstruction review if supported | Show possible road or sidewalk disruption. Distinguish the staff-only illustration from a reviewed reported obstruction |
| 2:15–2:35 | Simulate response assignment. Refresh phone status | One human decision updates the shared report across devices. No real crew is dispatched |
| 2:35–2:55 | Open municipal preview and simulate receipt | The overview includes the report link and fits the form limit. State that nothing is sent to Halifax |
| 2:55–3:00 | End on report link or QR | A citizen report has become evidence for a reviewable response decision |

If live analysis fails, show the preserved manual draft. For the AI explanation
beat, use the labelled cached example with its own photo. Never imply that cached
text was generated from the new upload. If shared storage fails, acknowledge it
and use the seeded demonstration rather than claiming a report was saved.

Photo reporting, citizen review, both maps, and shared state are required. Reserve
future fleet routing, weather modelling, power networks, and live municipal
integration for questions after the demo.
