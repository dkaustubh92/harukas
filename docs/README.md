# HaruKas documentation

Everything that isn't code. Four folders, numbered in reading order.

| Folder | Holds | Owner |
|---|---|---|
| [`01-hackathon/`](01-hackathon/) | Event facts — the runbook, the five challenges, the rubric. **Given to us; we don't edit the facts, only our notes on them** | Both |
| [`02-research/`](02-research/) | Problem-statement research. One file per challenge we investigate, plus data findings | Both |
| [`03-requirements/`](03-requirements/) | What we decided to build — demo script, scope, spec | Both |
| [`04-status/`](04-status/) | Where we are right now — checklist and decision log | KD |

## Start here

1. [`01-hackathon/challenges.md`](01-hackathon/challenges.md) — the five problems and **how we're judged**
2. [`01-hackathon/runbook.md`](01-hackathon/runbook.md) — the clock, the cut ladder, standing decisions
3. [`04-status/checklist.md`](04-status/checklist.md) — what's done, what's next

## Rules

- **Timestamp anything time-sensitive.** A file that says "currently" without a time is a trap by 14:00
- **Decisions go in [`04-status/decisions.md`](04-status/decisions.md)**, not in chat. One line each, with the reason
- **HA never edits this repo** — HA's docs live in the shared drive. Anything HA needs gets pasted in by KD
